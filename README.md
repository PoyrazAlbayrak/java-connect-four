# Connect Four (Java) 

A terminal-based Connect Four game developed in Java. This project focuses on pure logic, algorithmic thinking, and matrix (2D array) manipulation.

### 🧠 Key Features & Algorithms
* **Dynamic Grid:** Custom board generation based on user input for rows and columns.
* **Advanced Win-Checking Algorithm:** Features a robust 2D array traversal logic that accurately detects horizontal, vertical, and **diagonal** win conditions dynamically without running into `OutOfBounds` exceptions.
* **Terminal UI:** A clean, turn-based command-line interface.

### 🛠️ Technologies Used
* **Language:** Java
* **Concepts:** 2D Arrays, Multidirectional Loops, Algorithm Design, Object-Oriented Programming (OOP)
